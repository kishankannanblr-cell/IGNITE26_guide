# IGNITE 2026 — Tech Volunteer Interactive & Video Guide

Interactive hardware setup, live audio/video routing, and emergency troubleshooting guide for **IGNITE 2026** hosted by **Greenwood High International School, Bangalore** ([gwhignite.in](https://gwhignite.in/)).

## Features
- **🎮 Respawn (Gaming)**: Complete step-by-step setup & repair for **Xbox**, **PS4**, **Minecraft 4-Player LAN**, and **Roblox**.
- **🎬 Interactive Video Walkthroughs & Port Inspector**: Built-in animated hardware setup videos (with voiceover narration & Picture-in-Picture) + clickable port diagrams for Xbox, PS4, Stage PA Mixer, and Auditorium Projector.
- **🎭 All 12 Cultural Events**: Ranked by Tech Dependency (Critical, High, Medium, Low) with hardware checklists and rapid fixes.
- **🏆 All 8 Sporting Events**: FIBA 24s/14s Basketball Shot Clock, 10m Air Rifle/Pistol Electronic Targets, AstroTurf Floodlights & Outdoor PA.
- **🚨 30-Second Emergency Repair Wizard**: Instant symptom search for on-site troubleshooting.

## Deploying on Vercel
Import this repository directly into [Vercel](https://vercel.com/new) — no build step required (Framework Preset: **Other**).
